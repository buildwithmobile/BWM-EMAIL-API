# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, credentials, customer data, or sensitive security details in public issues.

Report security concerns privately through the official BWM Mail API contact page:

https://bwmemailapi.ct.ws/contact

Include a concise description, impact, reproduction steps, and any relevant sanitized evidence. Do not include live API keys, passwords, OTPs, or personal data.

## Credential exposure

If an API key is accidentally committed or shared, revoke or rotate it from the relevant account/project dashboard immediately. Removing the key from the latest commit does not guarantee that it has disappeared from repository history or caches.
